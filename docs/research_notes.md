# NilaGuard - Initial Research Notes

## Research Direction
Malayalam and Romanized Malayalam (Manglish) mixed-language
scam message analysis.

## Initial Research Observation
Multilingual phishing detection, explainability and privacy-aware
analysis are already active research areas.

NilaGuard will not claim these ideas are entirely new.

## Research Questions
1. How can mixed Malayalam, Manglish and English messages
   be analyzed using a common pipeline?
2. Can scam indicators be explained using traceable evidence?
3. Can message analysis operate locally without transmitting
   submitted content?
4. How can performance across different language formats
   be evaluated?
5. How can false positives and false negatives be documented?

## Proposed Focus
- Malayalam and Manglish language normalization.
- Explainable indicator-based analysis.
- Privacy-first local processing.
- Controlled synthetic dataset.
- Transparent testing and evaluation.

## Originality Status
Provisional research direction.

Originality must be evaluated through literature review,
existing tools, implementation and experimental results.

## Limitations
The prototype cannot guarantee scam detection.
A suspicious indicator does not prove a message is malicious.
A message without detected indicators is not guaranteed safe.
